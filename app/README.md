# Kicker Winrate Tracker

Веб-приложение для настольного футбола:

- учет матчей **1 на 1** и **2 на 2**;
- учет стороны в каждом матче: **желтая** / **белая**;
- автоматический расчет:
  - побед и поражений,
  - винрейта по игрокам,
  - статистики по стороне (желтая/белая);
- форматы соревнований:
  - **дружеские матчи** (идут в общий винрейт),
  - **рейтинговая сетка по очкам** (ladder),
  - **плей-офф сетка** (single elimination).

Интерфейс адаптирован под мобильные устройства (mobile-first).

## Стек

- React 19
- TypeScript
- Vite
- LocalStorage для сохранения данных в браузере

## Запуск

```bash
npm install
npm run dev
```

Откройте URL из консоли (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
npm run preview
```

## Где хранятся данные

Все данные сохраняются в `localStorage` браузера (ключ: `table-football-stats-v1`).
