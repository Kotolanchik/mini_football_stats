# mini_football_stats

Полноценное веб-приложение находится в папке [`app`](./app).

## Запуск одной командой через Docker Compose

```bash
docker compose up --build
```

Приложение будет доступно по адресу:

`http://localhost:8080`

## Локальная разработка (без Docker)

```bash
cd app
npm install
npm run dev
```
